The GPS Navigation Message

How a GPS satellite packs “where I am” and “what my clock says” into a 50 bit/s stream, and how a receiver turns those bits back into a satellite position good to about a metre.

01

Part I · Foundations

What the navigation message is, and why a receiver cannot work without it

A GPS satellite is a very good clock that flies on a known path and keeps shouting the time. A receiver measures how late each shout arrives, and turns delays into distances.

A distance is useless unless you know where the shouter was and how wrong its clock was. The navigation message is the part of the signal that tells you both. Think of a departure board that scrolls slowly: you must read it once before you can plan your trip.

The receiver measures a pseudorange to each satellite k. It is “pseudo” because it still contains clock errors. The message supplies the two satellite terms in this equation:

Pseudorange model \[ \rho^{(k)} = \underbrace{\lVert \mathbf r^{(k)}(t_{tx}) - \mathbf r_u \rVert}_{\text{needs satellite position}} + c\,\big(\delta t_u - \underbrace{\delta t^{(k)}}_{\text{needs clock model}}\big) + I^{(k)} + T^{(k)} + \varepsilon \]

\(c = 299\,792\,458\) m/s. \(I\) and \(T\) are ionosphere and troposphere delays; the message also helps with \(I\).

Error sensitivity \[ 1\ \text{ns of clock error} \;\Rightarrow\; c \cdot 10^{-9}\,\text{s} = 0.30\ \text{m of range error} \]

A satellite position error \(\delta\mathbf r\) adds at most \(\lVert\delta\mathbf r\rVert\) to the range (only its component along the line of sight counts).

Part I · Foundations

Where the message rides: 50 bit/s on top of the C/A code

Each satellite repeats its own 1023-chip pseudo-random code once every millisecond. To send a data bit, it plays that code normally for a 0, or upside down for a 1, and keeps doing so for 20 code periods.

It is like a tune played 20 times in a row, either in the normal key or inverted. The receiver knows the tune, so it can hear it even far below the noise, and it only has to decide “normal or inverted” every 20 ms.

Transmitted L1 C/A signal \[ s(t) = \sqrt{2P}\; D(t)\; C(t)\; \cos(2\pi f_{L1} t + \theta), \qquad D, C \in \{-1,+1\} \]

\(f_{L1} = 1575.42\) MHz. \(C(t)\) is the C/A code, \(D(t)\) the navigation data. With 0/1 logic the product is an exclusive-or: \(D \oplus C\).

From chips to bits, step by step \[ \begin{aligned} T_c &= \frac{1}{1.023\times10^{6}\ \text{chip/s}} = 977.5\ \text{ns} \\ T_{code} &= 1023\, T_c = 1.000\ \text{ms} \\ T_b &= 20\, T_{code} = 20\ \text{ms} \\ R_b &= 1/T_b = 50\ \text{bit/s} \end{aligned} \]
Energy per bit \[ \frac{E_b}{N_0}\Big|_{\text{dB}} = \frac{C}{N_0}\Big|_{\text{dB-Hz}} - 10\log_{10}(50) = \frac{C}{N_0}\Big|_{\text{dB-Hz}} - 17.0\ \text{dB} \]

A typical open-sky \(C/N_0\) of 45 dB-Hz gives \(E_b/N_0 = 28\) dB, a very clean bit decision. Section 12 shows what happens when it drops.

Data bit edges are aligned with code-period edges, so there is always a whole number of code periods (20) in a bit. Before it can read bits, a receiver must find where the 20 ms boundaries fall. This step is called bit synchronisation.

Part I · Foundations

Anatomy: bits, words, subframes, frames and the 12.5-minute cycle

The message is organised like a book. Bits are letters. A word is a line of 30 bits. A subframe is a page of 10 lines. A frame is a chapter of 5 pages. The whole book has 25 chapters.

Pages 1–3 of every chapter are the same until the satellite gets new data: they describe this satellite. Pages 4 and 5 change from chapter to chapter, so the receiver must read all 25 chapters to see everything.

Timing hierarchy \[ \begin{aligned} \text{word} &= 30 \text{ bits} \times 20\ \text{ms} = 0.6\ \text{s} \\ \text{subframe} &= 10 \text{ words} = 300 \text{ bits} = 6\ \text{s} \\ \text{frame} &= 5 \text{ subframes} = 1500 \text{ bits} = 30\ \text{s} \\ \text{superframe} &= 25 \text{ frames} = 37\,500 \text{ bits} = 750\ \text{s} = 12.5\ \text{min} \end{aligned} \]

Each word carries 24 data bits and 6 parity bits. Words 1 and 2 of every subframe are always the TLM and HOW words (section 4).

Subframe boundaries are tied to GPS time: a new subframe starts at every multiple of 6 s since the start of the GPS week (Sunday 00:00:00 GPS time). Subframe 1 starts at every multiple of 30 s.

Part II · The math inside the message

TLM and HOW: finding the start of a subframe and reading the time

Every page of the book starts with the same two lines. The first line (TLM, telemetry word) begins with a fixed 8-bit pattern, 10001011, so the receiver can spot where a page starts.

The second line (HOW, hand-over word) is a time stamp: it says what GPS time it will be when the next page starts. It also says which subframe (1–5) this is.

Z-count and TOW count \[ \text{Z-count} = \Big\lfloor \frac{t}{1.5\ \text{s}} \Big\rfloor, \qquad \text{TOW count} = \Big\lfloor \frac{\text{Z-count}}{4} \Big\rfloor \;\;(\text{17 MSBs of 19}) \]

\(t\) is GPS time of week in seconds, 0 to 604 799. One TOW-count unit is \(4 \times 1.5 = 6\) s, exactly one subframe. The largest value is \(604\,800/6 - 1 = 100\,799\), which fits in 17 bits (\(2^{17} = 131\,072\)).

Time of transmission from the HOW \[ t_{\text{sf}} = 6\ \text{s} \times (\text{TOW} - 1), \qquad t_{tx} = t_{\text{sf}} + n_b \cdot 20\ \text{ms} + n_c \cdot 1\ \text{ms} + \phi_{code}\, T_c \]

\(t_{sf}\) is the start of the current subframe. The receiver adds the bits \(n_b\), whole code periods \(n_c\) and code phase \(\phi_{code}\) (in chips of \(T_c = 977.5\) ns) it has counted since then. This is how GPS reports time to well below a microsecond.

Subframe ID from the time \[ \text{ID} = \big((\text{TOW} - 1) \bmod 5\big) + 1 \]

The HOW also holds an alert flag (do not trust this satellite’s accuracy) and an anti-spoof flag (the P code is encrypted to Y). The last two data bits of the HOW are not data: the satellite chooses them so that parity bits 29 and 30 come out as 0 (section 5).

An 8-bit preamble also appears by chance in random data, with probability \(2^{-8} = 1/256\) at any bit position. Receivers therefore confirm it twice, 6 s apart, and check parity before they trust it.

Parity: six check bits that catch errors and fix polarity

Each 30-bit word ends with 6 check bits computed from its 24 data bits, like the check digit on a bank card but six times over. If a bit flips on the way, the checks no longer match and the receiver throws the word away.

Parity has a second job. A receiver’s phase-lock loop cannot tell a signal from its upside-down copy, so every bit may arrive inverted. The parity rule is built so that an inverted word still passes, and tells the receiver to flip it back.

Encoding rule (IS-GPS-200, Table 20-XIV) \[ D_i = d_i \oplus D^*_{30}, \quad i = 1,\dots,24 \] \[ D_{24+j} = D^*_{s_j} \oplus \bigoplus_{i \in S_j} d_i, \qquad j = 1,\dots,6 \] \[ \begin{aligned} \text{e.g. } D_{25} = D^*_{29} &\oplus d_1 \oplus d_2 \oplus d_3 \oplus d_5 \oplus d_6 \oplus d_{10} \oplus d_{11} \\ &\oplus d_{12} \oplus d_{13} \oplus d_{14} \oplus d_{17} \oplus d_{18} \oplus d_{20} \oplus d_{23} \end{aligned} \]

\(d_i\) are source data bits, \(D_i\) transmitted bits, and \(D^*_{29}, D^*_{30}\) the last two transmitted bits of the previous word. The seed \(s_j\) and the index sets \(S_j\) are in the table below.

Why inversion is harmless

Suppose all 32 bits the receiver sees are inverted (\(D^*_{29}, D^*_{30}, D_1 \dots D_{30}\)). Recovering the data gives \(\bar D_i \oplus \bar D^*_{30} = D_i \oplus D^*_{30} = d_i\): the two inversions cancel and the data comes out right. Each parity equation has exactly one seed term (\(D^*_{29}\) or \(D^*_{30}\)), so every recomputed parity bit is inverted, exactly like the received ones. The word passes.

Acceptance test \[ \text{accept word} \iff \big(D_{25},\dots,D_{30}\big)_{\text{received}} = \big(D_{25},\dots,D_{30}\big)_{\text{recomputed}} \]

The code behaves like an extended Hamming code with minimum distance 4. It detects every 1-, 2- and 3-bit error and every odd number of errors. It corrects nothing.

How numbers are packed: scaled integers, two’s complement and semicircles

The message never sends “5153.67”. It sends a whole number and a rule such as “multiply by \(2^{-19}\)”. Prices work the same way: shops store cents, not fractions of a euro.

Angles are sent in semicircles: one semicircle is half a turn, π radians or 180°. A 32-bit angle can then cover the whole circle with very fine steps.

Scaling \[ x = N \cdot 2^{k}, \qquad N = \operatorname{round}\!\big(x / 2^{k}\big), \qquad |x - N 2^{k}| \le 2^{k-1} \]

\(2^k\) is the scale factor, also the value of the least significant bit (LSB). The worst rounding error is half an LSB.

Two’s complement for signed fields \[ N = -b_{n-1}\, 2^{\,n-1} + \sum_{j=0}^{n-2} b_j\, 2^{\,j} \]

An \(n\)-bit signed field covers \(-2^{n-1} \dots 2^{n-1}-1\). A 16-bit field covers −32 768 to 32 767.

Semicircles to radians \[ \alpha_{\text{rad}} = \pi \cdot \alpha_{\text{sc}}, \qquad \pi = 3.1415926535898 \]

IS-GPS-200 fixes π to exactly this value, and the receiver must use it. A different π would rotate every orbit by a tiny but needless amount.

Subframe 1: correcting the satellite clock

Each satellite carries atomic clocks, but even they drift by microseconds over days. Nobody adjusts them. Instead the ground stations measure the drift and upload a small parabola. The satellite broadcasts its three coefficients.

It is like owning a watch that runs 2 s fast per day: you do not reset it, you just remember the offset and the rate and do the sum.

Satellite clock correction \[ \Delta t_{sv} = a_{f0} + a_{f1}\,(t - t_{oc}) + a_{f2}\,(t - t_{oc})^2 + \Delta t_r \] \[ t = t_{sv} - \Delta t_{sv}, \qquad (\Delta t_{sv})_{L1} = \Delta t_{sv} - T_{GD} \]

\(t_{sv}\) is the time the satellite clock shows, \(t\) the true GPS time and \(t_{oc}\) the reference time of the polynomial. Single-frequency L1 users also subtract the group delay \(T_{GD}\). In practice one iteration of \(t \approx t_{sv}\) inside the polynomial is enough.

Relativistic term, derived

On an elliptical orbit the satellite speeds up and dips deeper in Earth’s gravity near perigee, so its clock rate changes around the orbit. Integrating the rate change gives a periodic term:

\[ \Delta t_r = F\, e \sqrt{A}\, \sin E_k, \qquad F = \frac{-2\sqrt{\mu}}{c^{2}} = -4.442807633\times10^{-10}\ \tfrac{\text{s}}{\text{m}^{1/2}} \]

With \(e = 0.02\) and \(\sqrt A = 5153.67\ \text{m}^{1/2}\) the amplitude is \(4.4428\times10^{-10} \times 0.02 \times 5153.67 = 45.8\) ns, or 13.7 m of range. Too big to ignore.

Subframes 2–3, part 1: the orbit in its own plane

A satellite orbit is very close to an ellipse with Earth’s centre at one focus. To find the satellite on that ellipse you need its size, its stretch, and a clock that tells you how far round it has gone.

The catch: the satellite does not move at constant speed. It is faster near Earth. So the message gives a “fake” angle that grows evenly with time (the mean anomaly \(M\)), and the receiver converts it to the real angle by solving Kepler’s equation.

Step 1 · Size and mean motion \[ A = \big(\sqrt A\big)^2, \qquad n_0 = \sqrt{\frac{\mu}{A^3}}, \qquad n = n_0 + \Delta n \]

\(\mu = 3.986005\times10^{14}\ \text{m}^3/\text{s}^2\) (Earth’s gravitational constant, IS-GPS-200 value). For \(A = 26\,560\) km the period is \(2\pi/n_0 = 43\,079\) s ≈ 11 h 58 min, half a sidereal day.

Step 2 · Mean anomaly now \[ t_k = t - t_{oe}, \qquad M_k = M_0 + n\, t_k \]

If \(|t_k| > 302\,400\) s, add or subtract 604 800 s to handle the end of the week.

Step 3 · Kepler’s equation, solved by iteration \[ M_k = E_k - e \sin E_k \quad\Rightarrow\quad E^{(j+1)} = M_k + e \sin E^{(j)}, \;\; E^{(0)} = M_k \]

Why it converges: the error shrinks by a factor \(|e\cos E| \le e\) each step. With \(e \approx 0.01\) every step gains about two decimal digits. Newton’s method \(E \leftarrow E - \frac{E - e\sin E - M}{1 - e\cos E}\) doubles the digits each step.

Step 4 · True anomaly and radius \[ \nu_k = \operatorname{atan2}\!\big(\sqrt{1-e^2}\,\sin E_k,\; \cos E_k - e\big), \qquad r = A\,(1 - e\cos E_k) \]

Subframes 2–3, part 2: tilting the plane and turning the Earth

Now place the ellipse in space with three angles: where it crosses the equator going north (\(\Omega\)), how steeply it is tilted (\(i\), about 55° for GPS), and where its closest point lies within the plane (\(\omega\)).

Then remember that the Earth turns under the orbit. A receiver works in Earth-fixed coordinates (ECEF), so the formulas subtract Earth’s rotation. Six small correction terms add the ripples caused mostly by Earth’s flattening.

Step 5 · Argument of latitude and corrections \[ \Phi_k = \nu_k + \omega \] \[ \begin{aligned} \delta u_k &= C_{us}\sin 2\Phi_k + C_{uc}\cos 2\Phi_k \\ \delta r_k &= C_{rs}\sin 2\Phi_k + C_{rc}\cos 2\Phi_k \\ \delta i_k &= C_{is}\sin 2\Phi_k + C_{ic}\cos 2\Phi_k \end{aligned} \]

The ripples have twice the orbital frequency. That is the signature of Earth’s equatorial bulge (the \(J_2\) term).

Step 6 · Corrected orbit values \[ u_k = \Phi_k + \delta u_k, \quad r_k = A(1 - e\cos E_k) + \delta r_k, \quad i_k = i_0 + \delta i_k + \dot i\, t_k \] \[ x'_k = r_k \cos u_k, \qquad y'_k = r_k \sin u_k \]
Step 7 · Node longitude in the rotating Earth frame \[ \Omega_k = \Omega_0 + (\dot\Omega - \dot\Omega_e)\, t_k - \dot\Omega_e\, t_{oe}, \qquad \dot\Omega_e = 7.2921151467\times10^{-5}\ \text{rad/s} \]

\(\Omega_0\) is referred to the start of the GPS week, which is why Earth’s rotation since then, \(\dot\Omega_e t_{oe}\), is subtracted.

Step 8 · Earth-fixed position \[ \begin{aligned} X_k &= x'_k \cos\Omega_k - y'_k \cos i_k \sin\Omega_k \\ Y_k &= x'_k \sin\Omega_k + y'_k \cos i_k \cos\Omega_k \\ Z_k &= y'_k \sin i_k \end{aligned} \]

In matrix form this is \(\mathbf r = R_3(-\Omega_k)\,R_1(-i_k)\,R_3(-u_k)\,[r_k, 0, 0]^T\): three rotations of a vector of length \(r_k\).

Sixteen orbit numbers in total: \(\sqrt A, e, M_0, \Delta n, \Omega_0, \dot\Omega, i_0, \dot i, \omega\), six \(C\) terms, and \(t_{oe}\). This curve fit is valid for a stated fit interval, normally 4 hours around \(t_{oe}\).

Subframes 4 and 5: almanac, ionosphere, UTC and health

Subframes 4 and 5 are a shared notice board. Every satellite sends the same content, one page per 30 s frame, cycling through 25 pages.

The almanac is a coarse orbit for every satellite, good enough to know which satellites are above the horizon and which codes to search for. The board also carries a simple ionosphere model and the offset between GPS time and UTC.

Almanac versus ephemeris

The almanac drops all six harmonic corrections, \(\Delta n\) and \(\dot i\), and sends fewer bits (e.g. \(\sqrt A\) in 24 bits at \(2^{-11}\) instead of 32 bits at \(2^{-19}\)). Inclination is sent as an offset \(\delta_i\) from 0.30 semicircles (54°). It stays usable for weeks, but with errors of kilometres rather than metres.

Klobuchar ionosphere model (single frequency) \[ T_{iono} = F \cdot \Big[\, 5\ \text{ns} + \text{AMP}\,\Big(1 - \frac{x^2}{2} + \frac{x^4}{24}\Big) \Big], \quad |x| < 1.57 \] \[ x = \frac{2\pi\,(t - 50\,400\ \text{s})}{\text{PER}}, \quad \text{AMP} = \sum_{n=0}^{3} \alpha_n \phi_m^{\,n}, \quad \text{PER} = \sum_{n=0}^{3} \beta_n \phi_m^{\,n} \]

A cosine-shaped daytime bump peaking at 14:00 local time on a 5 ns night floor. \(\phi_m\) is the geomagnetic latitude of the point where the signal crosses 350 km altitude, \(F = 1 + 16(0.53 - E)^3\) is the slant factor (\(E\) in semicircles), and AMP ≥ 0, PER ≥ 72 000 s. The model removes roughly half of the ionospheric delay on average.

GPS time to UTC \[ t_{UTC} = t_{GPS} - \big[\Delta t_{LS} + A_0 + A_1\,(t_{GPS} - t_{ot} + 604\,800\,(WN - WN_t))\big] \]

\(\Delta t_{LS}\) is the leap-second count: 18 s since 1 January 2017. \(A_0, A_1\) model the remaining nanosecond-level offset.

Part III · Real-world effects

Reading the message from a weak signal: bit errors and time to first fix

The receiver reads the message from a signal far weaker than the noise around it. Indoors or under trees the signal fades and bits start to flip.

One wrong bit spoils a whole word, because parity rejects it. A spoilt word in subframes 1–3 means waiting 30 s for the next copy. So the message fails quite suddenly as the signal weakens: a cliff, not a slope.

Bit error probability, coherent BPSK \[ P_b = Q\!\left(\sqrt{2E_b/N_0}\right) = \tfrac12 \operatorname{erfc}\!\left(\sqrt{E_b/N_0}\right), \qquad \frac{E_b}{N_0} = 10^{\left(C/N_0 - 17.0\right)/10} \]
From bits to words to an ephemeris \[ P_{word} = (1 - P_b)^{30}, \qquad P_{eph} = (1 - P_b)^{900}, \qquad \mathbb{E}[t_{eph}] \approx \frac{30\ \text{s}}{P_{eph}} \]

\(P_{eph}\) is the chance that subframes 1–3 (900 bits) of one frame all arrive clean. The last formula is a simple model: real receivers can combine clean subframes from different frames when IODE and IODC match.

Ideal coherent detection. Real receivers lose a dB or more to imperfect carrier tracking, so the cliff sits a little higher. Tracking a signal (keeping lock) works several dB below the level needed to read the message.

Time to first fix

A receiver that starts with no stored data must acquire the signal, find bit edges, find the preamble, then collect subframes 1–3. The fastest case is 18 s of data after frame sync; typical cold starts take 30–40 s. Stored or downloaded data skip the waiting.

Part III · Real-world effects

Timekeeping traps: the 1024-week rollover and leap seconds

The week number in subframe 1 has only 10 bits, so it counts 0 to 1023 and then starts again at 0. That happens every 19.6 years. A receiver that guesses the wrong 19.6-year era shows a date in the past.

GPS time also ignores leap seconds. UTC, the time on your phone, has added 18 since 1980. The message carries that number so receivers can convert.

Full week number \[ WN_{full} = WN_{10} + 1024\,k \] \[ \text{date} = \text{6 Jan 1980} + 7\,WN_{full}\ \text{days} + \text{TOW} \]

\(k\) is the number of rollovers. The message does not send it. Receivers usually take the smallest \(k\) that gives a date after their firmware build date, which works for 19.6 years after that date.

Rollover dates \[ 1024 \times 7 = 7168\ \text{days} \approx 19.62\ \text{years} \]

Rollovers happened at 00:00 GPS time on 22 Aug 1999 and 7 Apr 2019. The next is 21 Nov 2038. CNAV and CNAV-2 use 13 bits (8192 weeks, about 157 years), so their first rollover is in January 2137.

Part III · Real-world effects

Limits: speed, sensitivity, precision and trust

LNAV was designed in the 1970s. It is slow on purpose, so that weak signals can still be read. It has no error correction and no way to prove who sent it. Its numbers have a finite resolution, and its orbit model is only a curve fit.

Each limit can be measured against a theoretical bound. The gap shows where newer messages found room to improve.

Shannon limit at infinite bandwidth \[ R_{max} = \frac{C/N_0}{\ln 2} \quad\Rightarrow\quad \frac{C}{N_0}\Big|_{min} = 10\log_{10}(50 \ln 2) = 15.4\ \text{dB-Hz} \]

The second form is the weakest signal that could in theory carry 50 bit/s.

At 45 dB-Hz the bound is \(10^{4.5}/\ln 2 = 45\,600\) bit/s, about 900 times the LNAV rate. Uncoded BPSK needs \(E_b/N_0 = 9.6\) dB for \(P_b = 10^{-5}\), i.e. 26.6 dB-Hz. That leaves 11 dB between LNAV and the theoretical best.

Quantisation effect of one LSB \[ \delta\mathbf r \approx \frac{\partial \mathbf r}{\partial p}\, 2^{k_p} \]

Every orbit parameter \(p\) has an LSB \(2^{k_p}\). The figure computes \(\delta\mathbf r\) by running the full algorithm twice, with \(p\) and with \(p + 1\ \text{LSB}\). Two hours after \(t_{oe}\) the largest effects are a few centimetres (about 7 cm for \(\Delta n\) and \(\dot\Omega\)), far below the metre-level error of the orbit model itself. Resolution is not the limit. The model is.

Part IV · History and evolution

History: from Transit to today’s four global systems

Satellites have broadcast their own orbits since the 1960s. GPS inherited the idea from the US Navy’s Transit system and added precise time from atomic clocks.

The LNAV format first flew in 1978 and is still sent today, almost unchanged. Newer messages sit next to it on other signals instead of replacing it.

Part IV · History and evolution

Modern messages: packets, error correction and authentication

Newer messages work like network packets. Each 300-bit packet has a header that says what kind of data it carries, and a checksum (CRC) at the end. The satellite can send what is needed, when it is needed.

They also add forward error correction: extra coded symbols that let the receiver repair errors instead of only spotting them. And Galileo now signs its messages so receivers can tell a real satellite from a fake one.

CNAV message layout (300 bits) \[ \underbrace{8}_{\text{preamble}} + \underbrace{6}_{\text{PRN}} + \underbrace{6}_{\text{type}} + \underbrace{17}_{\text{TOW}} + \underbrace{1}_{\text{alert}} + \underbrace{238}_{\text{payload}} + \underbrace{24}_{\text{CRC}} = 300 \]
CRC-24Q generator polynomial \[ \begin{aligned} g(X) = X^{24}&+X^{23}+X^{18}+X^{17}+X^{14}+X^{11}+X^{10} \\ &+X^{7}+X^{6}+X^{5}+X^{4}+X^{3}+X+1 \end{aligned} \]

Undetected-error probability about \(2^{-24} \approx 6\times10^{-8}\) for random corruption, against 1/64 per word for LNAV parity.

Coding gain of the rate ½, K = 7 convolutional code \[ P_b \lesssim \sum_{d \ge 10} B_d\, Q\!\left(\sqrt{2 R d\, E_b/N_0}\right), \qquad R = \tfrac12 \] \[ B_{10}, B_{12}, \dots, B_{18} = 36,\ 211,\ 1404,\ 11\,633,\ 77\,433 \]

Soft-decision Viterbi decoding reaches \(P_b = 10^{-5}\) at about 4.2 dB instead of 9.6 dB: roughly 5 dB of gain. The cost is twice as many symbols on air.

Part VII · Summary

Five things to remember, and a glossary

  1. Slow by design. 50 bit/s on top of the C/A code: 20 code periods per bit, 30-bit words, 6 s subframes, 30 s frames, a 12.5 min cycle.
  2. Subframes 1–3 are about this satellite. A clock polynomial plus 16 orbit numbers valid for about 4 h. Subframes 4–5 are a shared board: almanac, ionosphere, UTC, health.
  3. Parity guards every word. Six bits per word detect all 1–3 bit errors and undo the 180° phase ambiguity. They correct nothing.
  4. Numbers are scaled integers. Angles are in semicircles; the receiver solves Kepler’s equation and applies three rotations to get an Earth-fixed position, accurate to about a metre.
  5. Know its limits. ≥ 18 s to read an ephemeris, ≈ 27 dB-Hz to read it cleanly, a 10-bit week that rolls over, no authentication. CNAV, CNAV-2 and Galileo add FEC, CRC, longer week counts and signatures.
